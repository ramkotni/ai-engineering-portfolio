# 08 - Functional Specification

## Modules
| Module | Inputs | Processing | Outputs | Validations / errors |
|---|---|---|---|---|
| Extraction | PDF, DOCX, HTML, MD, CSV | PDF: horizontal strips around tables/images for reading order, headings by font size >= 1.15x body, ruled tables to Markdown, metadata line parsed; DOCX: ordered walk, headings, tables, inline pictures; HTML: BS4; CSV: one record per row | Markdown + metadata + image files with `[[IMAGE:id]]` markers | Missing doc_id/revision/classification -> quarantine; unreadable file -> DLQ + alert |
| Vision captioning | image >= 120x120 px | Prompt: (1) transcribe text exactly, (2) describe flow/relations/numbers; cached by SHA-256 | caption | Failure -> "caption unavailable"; alert |
| Chunker | Markdown | Section-bounded; tables whole <= 2,500 chars; 800/100; contextual header; image and record chunks | chunks + metadata | Empty chunk dropped |
| Input guard | question | Injection, forced-restricted-doc attempts, medical/dosing, disposition commands, PII | clean text or `blocked` | > 2,000 chars -> 422 |
| Classify task | request | Endpoint or prefix rules: qa / summarize / search | task | Unknown -> qa |
| Authorize | role, task | Task allowed? Clearance? | proceed or `denied` | Denied lists allowed tasks |
| Retrieve | text, clearance | Clearance filter -> hybrid vector+BM25 RRF (k=6) -> exact LOT- lookup | chunks | None -> "not covered" |
| Grade | chunks | Drop weak/irrelevant chunks | filtered chunks | All dropped -> "not covered" |
| Generate | chunks, task | `qa/v1` or `summarize/v1` (`brief`/`detailed`/`executive`) | draft | LLM failure -> extractive passage with citation |
| Verify | draft | ID/number grounding; PII redaction | final answer + flags | Ungrounded -> caveat/removal |
| Documents / images | role | List visible documents; serve images after clearance check | JSON / PNG | 403 if above clearance; 404 unknown |
| Observability | request | metrics, audit, trace | `/metrics`, audit | Never fails the request |

## UI behavior
Question box with task tabs (Ask, Summarize, Search); answer panel with citation chips (doc ID, revision, section); figure thumbnails for image chunks with label "Caption generated by AI - verify against the controlled document"; classification badge on every source; document list limited to visible items; summary style selector; feedback with "missing content" option; reminder banner "Verify in the DMS before use in GxP records".

## AI behavior spec
| Aspect | Spec |
|---|---|
| Tone | Neutral, precise, short; executive summaries 5-8 lines |
| Citations | `[doc_id rev, section]`; figures `[doc_id, Figure n]`; numbers and IDs copied exactly |
| Refusals | Medical/dosing and disposition commands: "That is outside what I can do. QA decides disposition; the procedure is SOP-xxx." Explain process when asked how |
| Confidence | No retrieved chunk above threshold or all graded out -> "documents I can access do not cover this" (never answer from model memory) |
| Restricted info | Never mention that a restricted document exists to a user without clearance |
| Fallback-to-human | "Not covered", caption uncertainty, or conflicting revisions -> suggest contacting the document owner |
| Language | English (A-05) |

## Open questions
Threshold values for the grade step to be tuned on real documents; label wording for AI-generated captions to be approved by QA.
